# 流量杀手

纯前端的流量消耗 / 测速页：用多条并发连接循环下载同一个链接，实时统计速度、带宽和累计流量。

## 使用

1. 选择测试地址（或直接填自定义链接），设置线程数。
2. 点「开始」。
3. 点击「总流量」可设置上限（GB），达到后自动停止。

约束：

- **只接受支持跨域读取（CORS）的链接**。读不到字节的地址会被直接拒绝，不会用「请求数 × 文件大小」估算流量。
- 目标必须是 `https://`（浏览器安全限制）。
- 统计的是 `fetch` 读到的字节数。

## 部署

纯静态站点，任何静态托管都能用。仓库里的 `wrangler.toml` 用于 Cloudflare Pages：

```bash
npx wrangler pages deploy .
```

没有 Worker、没有构建步骤、没有依赖。

## 已知限制

- 统计的是解码后的字节：gzip 压缩的文本类资源会按解压后大小计入（图片 / 视频不受影响）。
- 页面切到后台会停止测试（浏览器会节流定时器），请保持前台。
- 挂代理 / VPN 时，运营商的定向流量通常不生效，这是运营商规则，不是工具问题。
